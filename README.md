# CP143: Dynamic Data Structures

A comprehensive, interactive learning module for **Dynamic Data Structures** in C programming, part of the CP143 course at Stellenbosch University.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/SwiftTuition/CP143-Dynamic-Data-Structures?quickstart=1)

## 📚 Module Contents

This module provides complete coverage of dynamic data structures including:

- **Self-referential Structures** - Building blocks for dynamic structures
- **Linked Lists** - Singly, doubly, and circular implementations
- **Stacks** - LIFO operations and applications
- **Queues** - FIFO operations and applications
- **Binary Search Trees** - Insertion, traversal, and searching
- **Memory Management** - malloc, free, and best practices

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Understand and implement self-referential structures
- Create and manipulate linked lists (singly, doubly, circular)
- Implement stack and queue data structures
- Build and traverse binary search trees
- Apply dynamic data structures to solve real-world problems
- Manage memory efficiently with malloc and free
- Debug and test dynamic data structure implementations
