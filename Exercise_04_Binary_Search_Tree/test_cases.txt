## Performance Notes:
1. **Balanced tree**: O(log n) for insert and search
2. **Skewed tree**: O(n) for insert and search (degrades to linked list)
3. **Inorder traversal**: Always O(n) - must visit every node
4. **Free tree**: Must use postorder to avoid accessing freed memory

---

## Understanding Traversals:

### Given tree:
```
        47
       /  \
     25    77
    /  \   /  \
   11  43 65  93
```

### Inorder (Left-Root-Right):
- Visit left subtree: 11, 25, 43
- Visit root: 47
- Visit right subtree: 65, 77, 93
- **Result**: 11 25 43 47 65 77 93 (sorted!)

### Preorder (Root-Left-Right):
- Visit root: 47
- Visit left subtree: 25, 11, 43
- Visit right subtree: 77, 65, 93
- **Result**: 47 25 11 43 77 65 93

### Postorder (Left-Right-Root):
- Visit left subtree: 11, 43, 25
- Visit right subtree: 65, 93, 77
- Visit root: 47
- **Result**: 11 43 25 65 93 77 47

---

## Common Mistakes to Avoid:
1. Not returning the modified tree in insert function
2. Freeing parent before children (causes access to freed memory)
3. Not handling NULL base case in recursive functions
4. Forgetting to check malloc return value
5. Not maintaining BST property (left < root < right)
6. Memory leaks from not freeing all nodes
