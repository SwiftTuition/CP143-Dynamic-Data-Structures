## Test Case 6: LIFO Verification
### Modification to main():
Verify that stack follows LIFO order:
```c
stack_node_t *top = NULL;

// Push in order: 1, 2, 3, 4, 5
for (int i = 1; i <= 5; i++) {
    push(&top, i);
    printf("Pushed: %d\n", i);
}

printf("\nPopping all elements (should be reverse order):\n");
while (!is_empty(top)) {
    printf("Popped: %d\n", pop(&top));
}
```

### Expected Output:
```
Pushed: 1
Pushed: 2
Pushed: 3
Pushed: 4
Pushed: 5

Popping all elements (should be reverse order):
Popped: 5
Popped: 4
Popped: 3
Popped: 2
Popped: 1
```

## Performance Notes:
1. All operations (push, pop, peek, isEmpty) should be O(1) - constant time
2. Only print_stack is O(n) where n is the number of elements
3. Stack operations should never need to traverse the entire structure

---

## Common Mistakes to Avoid:
1. Forgetting to update the top pointer after push/pop
2. Not checking for empty stack before pop/peek
3. Not freeing the popped node
4. Memory leaks when freeing the entire stack
5. Dereferencing NULL pointers
