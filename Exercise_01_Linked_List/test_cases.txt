# Test Cases for Exercise 1: Basic Linked List Operations

## Test Case 1: Normal Execution (provided in main)
### Description:
Tests all basic operations: add_end, add_beginning, remove_by_value, print_list, free_list

### Input:
- Create initial node with value 5
- Add 10 to end
- Add 3 to beginning
- Add 7 to end
- Remove value 10

### Expected Output:
```
Initial list:
3 -> 5 -> 10 -> 7 -> NULL

After removing 10:
3 -> 5 -> 7 -> NULL

All memory freed successfully.
```

## Test Case 5: Single Element List
### Modification to main():
Create a list with just one element and test operations:
```c
node_t *head = malloc(sizeof(node_t));
head->val = 42;
head->next = NULL;

printf("Single element list:\n");
print_list(head);

remove_by_value(&head, 42);
printf("\nAfter removing the only element:\n");
if (head == NULL) {
    printf("List is now empty (head is NULL)\n");
} else {
    print_list(head);
}
```

### Expected Output:
```
Single element list:
42 -> NULL

After removing the only element:
List is now empty (head is NULL)
```

## Notes for Testing:
1. All test cases should be run with valgrind to ensure no memory leaks
2. The solution should handle edge cases gracefully (empty list, single element, etc.)
