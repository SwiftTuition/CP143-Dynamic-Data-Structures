## Test Case 5: FIFO Verification
### Modification to main():
Verify that queue follows FIFO order:
```c
queue_t q;
init_queue(&q);

// Enqueue in order: 1, 2, 3, 4, 5
for (int i = 1; i <= 5; i++) {
    enqueue(&q, i);
    printf("Enqueued: %d\n", i);
}

printf("\nDequeuing all elements (should be same order):\n");
while (!is_empty(&q)) {
    printf("Dequeued: %d\n", dequeue(&q));
}
```

### Expected Output:
```
Enqueued: 1
Enqueued: 2
Enqueued: 3
Enqueued: 4
Enqueued: 5

Dequeuing all elements (should be same order):
Dequeued: 1
Dequeued: 2
Dequeued: 3
Dequeued: 4
Dequeued: 5
```

## Performance Notes:
1. All operations (enqueue, dequeue, peek, isEmpty) should be O(1) - constant time
2. Only print_queue is O(n) where n is the number of elements
3. Having both head and tail pointers is crucial for O(1) enqueue

---

## Common Mistakes to Avoid:
1. Forgetting to update tail pointer when enqueuing
2. Not handling the special case of single element queue
3. Not setting tail to NULL when dequeuing the last element
4. Not checking for empty queue before dequeue/peek
5. Not freeing all nodes in free_queue
6. Forgetting to reset both head and tail after freeing all nodes

---

## Comparison: Stack vs Queue Behavior

### Stack (LIFO):
```
Push: 1, 2, 3, 4, 5
Pop all: 5, 4, 3, 2, 1 (reverse order)
```

### Queue (FIFO):
```
Enqueue: 1, 2, 3, 4, 5
Dequeue all: 1, 2, 3, 4, 5 (same order)
```
